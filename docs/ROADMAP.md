## 已知问题

- 外部 JS 主动调用 Module.evalTJS 时，观察到间歇性的 Embind deleted-val 错误，尚未定位。游戏内 TJS Timer 驱动的视频回归已通过；两者不能混为一个结论。
- 构建仍有既存 JXR StrIODecTerm / StrIOEncTerm 签名警告，相关格式尚未纳入验收。
- 官方桌面引擎、手机 Kirikiroid2、公开重建分支和本项目的行为不能自动视为等价。
- 多引擎目前只有注册结构；没有实现的引擎不应显示为可玩。
- 公开版构建步骤需要预先准备与 ABI 匹配的依赖库，还不是一键编译整个引擎。
